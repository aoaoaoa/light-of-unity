# How powerful is the light of unity?

Two one-page sites built from the Bahá'ís of the United States carousel of the National Spiritual Assembly's letter of June 19, 2020, with echoes from Bahá'í literature.

- `v1/` Two Voices: the letter and its echoes as a two-column spread in eight color bands.
- `v2/` The Letter, Glossed: the passages read in one measure, echoes as numbered margin glosses, sources at the foot.
- `index.html` landing page linking both.
- `data.py` the transcribed passages, echoes and sources; `build.py` regenerates all pages (`python3 build.py`, then copy `site/` to the repo root).

Published with GitHub Pages from `main` via `.github/workflows/pages.yml`. Original letter: https://link.bahai.us/juneteenth
