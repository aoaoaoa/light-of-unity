# How powerful is the light of unity?

A one-page site built from the Bahá'ís of the United States carousel of the National Spiritual Assembly's letter of June 19, 2020, with echoes from Bahá'í literature: the letter and its echoes as a two-column spread in eight color bands.

- `index.html` the published page.
- `data.py` the transcribed passages, echoes and sources; `build.py` regenerates the page (`python3 build.py`, then copy `site/index.html` to the repo root). The script also keeps an unpublished second layout, `out/letter-glossed.html`.

Published with GitHub Pages from `main` via `.github/workflows/jekyll-gh-pages.yml`. Original letter: https://link.bahai.us/juneteenth
